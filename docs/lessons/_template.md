**Status:** idea | outlined | specified | built
**Builds on:** lesson numbers
**Estimated sections:** n

An outlined lesson contains only: goal, key concepts, section titles with one line each,
main experiment, quiz ideas, components and theory, and open questions. A specified
lesson fills in every section below.

## Goal
What you should be able to understand, hear or do after this lesson. One to three sentences.

## Key concepts
The terms and ideas introduced, each with a one-line definition.

## Sections
Each section follows hear → see → read → try. Describe every part concretely enough to
implement without guessing.

### 1. Section title
- **Hear:** the audio example that opens the section (what plays, instrument, tempo).
- **See:** what is shown or animated (piano highlights, cards, diagrams).
- **Read:** draft explanation text, short and conversational.
- **Try:** the interaction the user performs, and what feedback they get.

## Experiments
"Break the rule and listen" moments: what is changed, what to listen for, and the
explanation shown afterwards.

## Quiz
Question types, how questions are generated (preferably from the theory engine so they
vary per attempt), number of questions, and what counts as correct.

## Genre connections
Where the concept shows up in real music, per genre, with example progressions
(Roman numerals, no song references needed).

## Components and theory functions
- Existing components used.
- New components needed (also add them to the table in docs/curriculum.md).
- New theory functions needed, with the tests they require.

## Out of scope
What this lesson deliberately leaves for later lessons.
