# 09: Modes as moods

**Status:** outlined
**Builds on:** 01, 08

## Goal
Hear the main modes by their characteristic note and chord, and use them to set a mood.

## Key concepts
- **Mode:** a scale with a different home note within the same set of notes, or
  equivalently, major or minor with one or two notes altered.
- **Characteristic note:** the note that sets a mode apart: Lydian #4, Mixolydian b7,
  Dorian natural 6, Phrygian b2, Locrian b2 and b5.
- **Brightness order:** Lydian, Ionian, Mixolydian, Dorian, Aeolian, Phrygian, Locrian.
- **Characteristic progressions:** I–II (Lydian), I–bVII (Mixolydian), i–IV (Dorian), i–bII (Phrygian).

## Sections
1. **Two ways to see modes:** rotations of the major scale versus altered major/minor;
   the app favors the second because it's easier to hear.
2. **Brightness:** a slider from darkest to brightest over a drone.
3. **Dorian:** minor with a raised 6th; the major IV in a minor key.
4. **Mixolydian:** major with a flat 7th; the bVII.
5. **Lydian:** major with a raised 4th; dreamy, often used in film.
6. **Phrygian:** minor with a flat 2nd; dark, Spanish or metal.
7. **Vamps:** two-chord loops that make each mode unmistakable.

## Main experiment
One melody played over a drone while switching modes; only one note changes each time.

## Quiz ideas
Ear: which mode is this vamp; name the characteristic note of a mode.

## Components and theory
- **New:** drone and mode playground; brightness slider.
- **Theory:** `spellMode(tonic, mode)` for all seven modes, `characteristicNote(mode)`.
